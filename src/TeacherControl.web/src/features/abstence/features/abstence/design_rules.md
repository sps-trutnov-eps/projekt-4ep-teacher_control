# Design rules for Abstence feature

This document describes the UI/UX guidelines for the Abstence feature.

## Colors

- Primary color: #1655A3
- Secondary color: #173B70
- Background color: #FFFFFF
- Text color: #333333
- Border color: #D9E3F0

## Layout

- Top bar with title "ABSTENCE" on the left
- Mode toggle button (dropdown) in the top right corner
- Main content area below the top bar

## Components

- Top bar with title and mode toggle
- Teacher list with search functionality
- Teacher detail view with tabs (Preview / Rate)
- Mood meter component
- Delay form component

## Responsive Behavior

- Desktop: side-by-side layout (list on left, detail on right)
- Mobile: stacked layout with collapsible rows
