\# Pololetní hlasování - MUST



\## 1. Karta učitele (backend prototyp)

\*\*Vlastník:\*\* Čestmír Kalousek

\*\*Co umí:\*\* Seznam učitelů; po výběru učitele se vypíšou jeho informace z databáze, ověří se autorizace a autorizovaný uživatel může hlasovat. Hlas se zapíše do databáze a hned se zobrazí u učitele.

\*\*Hotovo, když:\*\* po výběru učitele se zobrazí jeho údaje a autorizovaný uživatel může hlasovat, hlas se uloží do databáze a ihned se zobrazí.



\## 2. Stránky hlasování (frontend)

\*\*Vlastník:\*\* Denis Molodčij

\*\*Co umí:\*\* 2 HTML + 2 CSS soubory podle layoutu prototypu. Výběr kategorií (nadpis s informacemi o hlasování, tlačítko hlavní kategorie, 4 podkategorie s placeholder názvy) a hlasování (karty učitelů, tlačítka pro hlasování, provizorní text místo backendu).

\*\*Hotovo, když:\*\* oba soubory existují, odpovídají prototypu a stylově sedí do aplikace.



\## 3. Stránky výsledků (frontend)

\*\*Vlastník:\*\* Adam Vojtěch

\*\*Co umí:\*\* 2 HTML + 2 CSS soubory podle layoutu prototypu s designem konce soutěže (např. medaile, pohár). Výběr kategorií (nadpis, tlačítko hlavní kategorie, 4 podkategorie s placeholder názvy) a žebříček s provizorními osobami a umístěním.

\*\*Hotovo, když:\*\* oba soubory existují, odpovídají prototypu, mají téma konce soutěže a stylově sedí do aplikace.
