# Rating

## Backend

**Co umí:** API server pro komunikaci mezi frontendem a databází

**Hotovo, když:** bude číst data z databáze, vypočítávat hodnocení (recenze, abstenci, a bingovost) a posílat je společně s dalšími údaji (fotografií, jménem, příjmením, bio a oceněním) na frontend

**Vlastník:** Adam Bureš

## Frontend

**Co umí:** Grafické rozhraní pro zobrazování dat z databáze v podobě profilu učitele

**Hotovo, když:** bude zobrazena fotografie, jméno, příjmení, bio, hodnocení (recenze, abstenci, bingovost) a ocenění pomocí dat získaných z API

**Vlastník:** Jakub Kneifel
