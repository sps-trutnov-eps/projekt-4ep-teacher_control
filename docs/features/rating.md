# Rating

## Backend (API server)

**Co umí:** Poskytovat data z databáze na základě požadavků frontendu.

**Hotovo, když:** bude úspěšně číst data z databáze, vypočítávat hodnocení (recenze, abstence a bingovost) a odesílat je společně s dalšími údaji (fotografií, jménem, příjmením, biem a oceněním) na vyžádání frontendu.

**Vlastník:** Adam Bureš

## Frontend (Grafické rozhraní)

**Co umí:** Vyžádat si potřebná data od API serveru a zobrazit je v podobě profilu učitele.

**Hotovo, když:** bude zobrazovat fotografii, jméno, příjmení, bio, hodnocení (recenze, abstence, bingovost) a ocenění pro daného učitele podle dat získaných z API serveru.

**Vlastník:** Jakub Kneifel
